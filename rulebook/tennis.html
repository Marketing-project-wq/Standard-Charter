Terkonfirmasi sumber resmi · dicek 16 Okt 2026

  • Di ITF World Tennis Tour 2026, match tie-break 10 poin menggantikan set ketiga dan no-ad dipakai. Ini regulasi turnamen, bukan Rules of Tennis. Ringkasan perubahan WTT 2026
  • Hitungan poin: love, 15, 30, 40, game. Jika kedua pihak menang tiga poin, skornya deuce. Pemenang poin berikutnya mendapat advantage, dan harus menang dua poin berturut-turut setelah deuce untuk memenangkan game. Skor server selalu disebut lebih dulu. ITF Rules of Tennis
  • Penerima menjadi server di akhir setiap game standar. Di ganda, tim yang mendapat giliran servis di game pertama tiap set memutuskan siapa yang melayani game itu. ITF Rules of Tennis 2026 (Rule 14)
  • Set: tie-break set dimenangkan pemain pertama yang menang 6 game dengan selisih 2, dan pada 6–6 dimainkan tie-break. Tie-break ke 7 poin dengan selisih 2. Poin pertama dilayani pemain yang gilirannya, lalu lawan melayani dua poin, lalu bergantian dua poin. Advantage set atau tie-break set diumumkan penyelenggara sebelumnya. Match tie-break 10 poin dapat menggantikan set penentu. ITF Rules of Tennis 2026
  • Foot fault: selama gerakan servis server tidak boleh berpindah posisi dengan berjalan atau berlari (gerakan kaki kecil boleh), dan tidak boleh menyentuh garis dasar atau lapangan dengan kaki mana pun. ITF Rules of Tennis 2026
  • Let servis: bola mengenai net dan servisnya tetap baik, atau servis dilakukan saat penerima belum siap. Servis diulang dan tidak membatalkan fault sebelumnya. Pada semua kasus let, seluruh poin diulang kecuali let pada servis kedua, yang hanya mengulang servis kedua. Beberapa turnamen memakai aturan No-Let. ITF Rules of Tennis 2026
  • Hindrance: jika pemain terganggu oleh tindakan sengaja lawan, pemain itu memenangkan poin. Jika terganggu oleh tindakan tidak sengaja atau hal di luar kendali, poin diulang. Raket jatuh atau sepatu lepas tidak dianggap hindrance. ITF Rules of Tennis 2026 ITF Duties and Procedures for Officials 2026

5.1 Ringkasan format

  • Tunggal atau ganda. Best of 3 set (atau satu set untuk mempersingkat ).

5.3 Jalannya pertandingan

  1. Undian: pemenang memilih servis, return, atau sisi.
  2. Servis: dari belakang garis dasar, diagonal ke kotak servis lawan. Dua kesempatan per poin.
  3. Server berpindah sisi tiap poin (kanan di poin genap, kiri di poin ganjil).
  4. Servis bergantian setiap game.
  5. Ganti sisi setelah game ganjil (1, 3, 5, ...) dengan jeda 90 detik. Setelah set, jeda 120 detik. ⚠️ Verifikasi
  6. Jeda antar poin: maksimal 25 detik.

5.4 Aturan skor

  • Poin: 0, 15, 30, 40, game.
  • Deuce (40–40): butuh unggul 2 poin. Poin pertama setelah deuce = advantage (Ad). No-ad: di deuce, satu poin menentukan game.
  • Set: sampai 6 game, selisih 2. Jika 6–6: tie-break.
  • Tie-break: sampai 7 poin, selisih 2. Server pertama melakukan satu servis, lalu bergantian dua servis. Ganti sisi tiap 6 poin.
  • Pertandingan: best of 3 set. Set ketiga bisa diganti match tie-break 10 poin.

5.8 Perhitungan dan klasemen

  • Contoh: 6–3, 6–7(5), 10–8 → pemenang 2–1 set.
  • Liga: menang 3 poin (atau 2), tie-breaker selisih set → selisih game.
