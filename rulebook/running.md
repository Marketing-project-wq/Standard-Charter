# 20. Running (Lari)

> Kategori: Individu

> **Dokumen acuan:** World Athletics, *Competition Rules (Technical Rules)*.

> **Terkonfirmasi sumber resmi** · dicek 16 Okt 2026
>

Jika tidak ada athlete yang bertanggung jawab, semua athlete diberi kartu hijau tanpa peringatan. [World Athletics Technical Rules](https://worldathletics.org/download/download?filename=92a127cb-d569-4db3-88e8-370e634ab2cd.pdf&urlslug=C2.1%2B-%2BTechnical%2BRules)

Pelanggaran jalur pertama diberi peringatan dan yang kedua dalam lomba yang sama didiskualifikasi. Athlete yang terdorong keluar jalur tidak didiskualifikasi jika tidak mendapat keuntungan dan tidak mengganggu lain. [World Athletics Technical Rules](https://worldathletics.org/download/download?filename=92a127cb-d569-4db3-88e8-370e634ab2cd.pdf&urlslug=C2.1%2B-%2BTechnical%2BRules)

[World Athletics Technical Rules](https://worldathletics.org/download/download?filename=92a127cb-d569-4db3-88e8-370e634ab2cd.pdf&urlslug=C2.1%2B-%2BTechnical%2BRules)

## 20.1 Ringkasan format

- **Jarak belum diketahui** (bisa sprint 100 m, 400 m, 5K, atau 10K). **Wajib dikonfirmasi.**
- Peringkat berdasarkan **waktu**.
- Berdasarkan aturan **World Athletics**.

## 20.2 Lintasan dan perlengkapan

| Bagian | Penjelasan |
|---|---|
| Lintasan stadion | 400 m, 8 jalur |
| Rute jalan (*road race*) | Rute di jalan, dengan titik air (*aid station*) dan pos pengawas |
| Nomor dada (*bib*) | Wajib terlihat, tidak boleh dipindahtangankan |
| Chip timing | Alat waktu di bib atau sepatu |

## 20.3 Jalannya lomba

1. **Panggilan**: pelari berkumpul di zona start (*pen* atau *wave*).
2. **Start**: aba-aba "On your marks" (sprint) atau tembakan/horn.
3. **Lomba**: pelari menempuh jarak. Di sprint, tetap di jalur sendiri (hingga garis pecah jalur).
4. **Finis**: pelari melewati garis finis. Waktu dicatat.
5. **Cut-off**: batas waktu maksimal. Pelari yang melewati dianggap DNF (road race).

## 20.4 Kamus istilah dan pelanggaran

| Istilah | Penjelasan detail | Akibat |
|---|---|---|
| **False start** | Berangkat sebelum aba-aba start. | **DQ** (satu false start menurut aturan World Athletics) |
| **Lane violation** | Keluar dari jalur sendiri atau menginjak garis jalur (sprint). | DQ jika menguntungkan atau mengganggu orang lain |
| **Obstruction** | Mendorong, menghalangi, atau mengganggu pelari lain. | Peringatan atau DQ |
| **Course cutting** | Memotong rute yang ditentukan. | DQ |
| **Outside assistance** | Menerima bantuan tidak sah (pacer di luar aturan, menerima minuman di luar pos resmi). | DQ atau penalti |
| **Bib swap** | Memindahtangankan nomor dada. | DQ |
| **Gun time** | Waktu dari tembakan start sampai finis. | — |
| **Chip time** | Waktu dari melewati garis start sampai finis. | — |
| **Pace** | Waktu per kilometer = waktu ÷ jarak. | — |
| **Recall** | Start diulang jika ada gangguan atau false start oleh petugas. Padanan dari *let*. | — |

## 20.5 Disiplin

| Pelanggaran | Sanksi |
|---|---|
| False start | DQ |
| Memotong rute | DQ |
| Bantuan tidak sah | Penalti waktu atau DQ |
| Obstruction | Peringatan atau DQ |

## 20.6 Status hasil

| Istilah | Di lari |
|---|---|
| **DNS** | Pelari terdaftar tapi tidak mengambil start. |
| **DNF** | Pelari berhenti atau melewati batas waktu (*cut-off*) tanpa finis. |
| **DQ** | False start, memotong rute, bantuan tidak sah, bib dipindahtangankan. |
| **Forfeit / W/O** | Tidak berlaku pada lomba individu. Tim relay yang tidak hadir = DNS. |
| **RET** | Pelari berhenti karena cedera di tengah rute. Dicatat DNF. |
| **Let** | Tidak ada. Padanannya ***recall / restart***. |
| **Fault** | Pelanggaran memicu DQ atau penalti waktu. |

## 20.7 Perhitungan dan klasemen

- **Peringkat resmi** biasanya mengikuti *gun time*. Waktu pribadi memakai *chip time*. Cek aturan event.
- **Pace**: 10 km dalam 50:00 → 5:00 per km. Rumus: waktu total ÷ jarak.
- **Seri**: foto finis menentukan. Jika masih sama, posisi sama.
- **Peringkat tim** (jika ada): jumlah posisi anggota terbaik.
