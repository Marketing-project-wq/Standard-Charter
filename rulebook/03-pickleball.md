# 3. Pickleball

> Kategori: Net dan raket

> **Dokumen acuan:** USA Pickleball dan IPPF, *Official Rulebook*.

> **Terkonfirmasi sumber resmi** · dicek 16 Okt 2026
>
> - Non-volley zone (kitchen) adalah area 7 kaki dari net di kedua sisi, tempat pemain tidak boleh memukul bola sebelum memantul. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf)
> - Aturan dua pantulan: penerima membiarkan servis memantul, lalu tim server membiarkan return memantul sebelum boleh di-volley. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf)
> - Game ke 11 dengan selisih minimal 2 adalah standar. Turnamen boleh memakai game ke 15 atau 21. Pada skor standar hanya tim server yang mencetak poin, server bergantian kotak servis dan terus melayani sampai kalah rally. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf) [Ringkasan aturan USAP](https://usapickleball.org/docs/rules/USAP-Rules-Summary.pdf)
> - Foot fault servis: minimal satu kaki server menyentuh area servis yang benar saat servis dipukul. Jika kedua kaki di udara saat servis dipukul, itu fault. Tidak boleh ada kaki yang menyentuh lapangan saat servis dipukul. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf)
> - Servis 2026 harus melewati non-volley zone dengan atau tanpa menyentuh net, dan mendarat di kotak servis yang benar. Drop serve diperbolehkan: bola dijatuhkan dari ketinggian berapa pun tetapi tidak boleh dilempar atau diberi gaya tambahan. Drop serve ilegal adalah fault servis. Status provisional drop serve dicabut. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf) [Dokumen perubahan 2026](https://usapickleball.org/docs/rules/USAP-Rulebook-Change-Document.pdf)
> - Jika return servis mengenai net lalu mendarat di non-volley zone, permainan berlanjut normal. Usulan let untuk kasus itu belum menjadi aturan. [USAP Rulebook 2026](https://usapickleball.org/docs/rules/USAP-Official-Rulebook.pdf)
> - Perubahan 2026: servis harus diarahkan ke kotak servis diagonal dari posisi yang benar. Rally scoring adalah opsi provisional (game ke 11, 15, atau 21, poin di setiap rally). Bola yang mengenai benda permanen setelah memantul di lapangan seorang pemain kini fault bagi pemain itu. Rulebook baru berlaku 1 Januari 2027. [Dokumen perubahan 2026](https://usapickleball.org/docs/rules/USAP-Rulebook-Change-Document.pdf)

## 3.1 Ringkasan format

- Tunggal atau ganda. Lapangan kecil, paddle padat, bola plastik berlubang.
- Game ke 11, selisih 2. Hanya **server** yang bisa mencetak poin (*side-out scoring*).

## 3.2 Lapangan dan perlengkapan

| Bagian | Ukuran |
|---|---|
| Lapangan | 20 ft × 44 ft (6,1 m × 13,4 m) |
| Tinggi net | 36 in (91 cm) di sisi, 34 in (86 cm) di tengah |
| Non-volley zone (kitchen) | 7 ft (2,1 m) dari net di kedua sisi |

## 3.3 Jalannya pertandingan

1. **Servis**: *underhand*, bola dipukul di bawah pinggang. Bola dipukul dari belakang garis dasar dan diagonal ke kotak servis lawan.
2. **Servis valid**: harus mendarat di kotak servis diagonal, **tidak di kitchen**.
3. **Double bounce rule**: servis harus memantul dulu di sisi penerima, dan return servis harus memantul dulu di sisi server. Setelah itu, bola boleh di-volley.
4. **Rally**: berlanjut sampai ada kesalahan.
5. **Poin**: jika **server menang rally**, server mendapat 1 poin dan servis lagi dari sisi lain. Jika **penerima menang rally**, **side-out** (servis pindah), tidak ada poin.
6. **Ganda**: kedua partner bisa melakukan servis sebelum side-out. Server pertama di awal game hanya satu (*0-0-2*).
7. **Pergantian sisi**: biasanya saat game ke 11 selesai, atau di tengah game 3.

## 3.4 Aturan skor

- Game ke **11**, selisih **2**. Sebagian turnamen memakai game ke 15 atau 21.
- Ganda dipanggil dalam tiga angka: **skor server – skor penerima – nomor server (1 atau 2)**.
  - Contoh: "4-3-2" = tim server 4, tim lawan 3, server kedua melakukan servis.
- Singles memakai dua angka.
- Satu pertandingan umumnya satu game atau best of 3 game.

## 3.5 Kamus istilah dan pelanggaran

| Istilah | Penjelasan detail | Hukuman |
|---|---|---|
| **Kitchen / NVZ** | Zona 7 ft dari net. Pemain tidak boleh memukul bola yang belum memantul (*volley*) saat berdiri di zona ini. | — |
| **Kitchen fault** | Kaki menyentuh garis NVZ atau berada di zona saat melakukan volley. Termasuk jika momentum membawa tubuh masuk zona **setelah** volley dalam satu rangkaian gerak. | Server fault → side-out; receiver fault → poin server |
| **Foot fault (servis)** | Kaki server menyentuh garis belakang atau lapangan sebelum bola dipukul. Minimal satu kaki harus di belakang garis dasar dan tidak melewatinya. | Servis salah |
| **Double bounce rule** | Servis dan return harus memantul dulu. Volley pada kedua bola awal ini adalah fault. | Fault |
| **Out** | Bola mendarat di luar garis. Garis termasuk area masuk. | Fault |
| **Net** | Bola tersangkut di net tanpa melewatinya. | Fault |
| **Hit by body** | Bola mengenai pemain atau pakaian sebelum memantul. | Fault (pemain yang terkena kalah rally) |
| **Paddle touching net** | Paddle atau badan menyentuh net saat bola dalam permainan. | Fault |
| **Let** | Aturan *let* servis (servis menyentuh net lalu masuk) **berbeda antar versi aturan** ⚠️ Verifikasi. Gangguan dari luar (bola masuk) selalu diulang. | Diulang |
| **Side-out** | Perpindahan hak servis ke tim lawan. | — |

## 3.6 Disiplin dan penalti

| Tingkat | Sanksi |
|---|---|
| Peringatan | Peringatan lisan |
| Technical foul | Poin untuk lawan atau kehilangan servis |
| Pelanggaran berat/berulang | Forfeit pertandingan atau DQ dari turnamen |

## 3.7 Status hasil

| Istilah | Di pickleball |
|---|---|
| **DNS** | Pemain tidak hadir saat dipanggil, forfeit. |
| **DNF** | Pertandingan tidak selesai (cedera, cuaca). |
| **DQ** | Technical foul berulang atau perilaku berat. |
| **Forfeit / W/O** | Tidak hadir atau mundur. Skor ditentukan turnamen. |
| **RET** | Mundur karena cedera. Lawan menang. |
| **Let** | Servis let (versi tertentu), gangguan luar. Diulang. |
| **Fault** | Kesalahan oleh **server** = *side-out* (tidak ada poin). Kesalahan oleh **penerima** = poin untuk server. |

## 3.8 Perhitungan dan klasemen

- Contoh: server tim A menang 4 rally berturut-turut → 4 poin. Side-out → B melakukan servis. Skor tim A 4, tim B 0 → dipanggil "4-0-1".
- Liga: menang 2 poin, kalah 0. Tie-breaker: head-to-head → selisih poin.
