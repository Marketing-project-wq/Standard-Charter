# 5. Tennis

> Kategori: Net dan raket

> **Dokumen acuan:** ITF (International Tennis Federation), *Rules of Tennis*.

> **Terkonfirmasi sumber resmi** · dicek 16 Okt 2026
>
> - Di ITF World Tennis Tour 2026, match tie-break 10 poin menggantikan set ketiga dan no-ad dipakai. Ini regulasi turnamen, bukan Rules of Tennis. [Ringkasan perubahan WTT 2026](https://www.itftennis.com/media/15547/2026-wtt-summary-of-rule-changes.pdf)
> - Hitungan poin: love, 15, 30, 40, game. Jika kedua pihak menang tiga poin, skornya deuce. Pemenang poin berikutnya mendapat advantage, dan harus menang dua poin berturut-turut setelah deuce untuk memenangkan game. Skor server selalu disebut lebih dulu. [ITF Rules of Tennis](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf)
> - Penerima menjadi server di akhir setiap game standar. Di ganda, tim yang mendapat giliran servis di game pertama tiap set memutuskan siapa yang melayani game itu. [ITF Rules of Tennis 2026 (Rule 14)](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf)
> - Set: tie-break set dimenangkan pemain pertama yang menang 6 game dengan selisih 2, dan pada 6–6 dimainkan tie-break. Tie-break ke 7 poin dengan selisih 2. Poin pertama dilayani pemain yang gilirannya, lalu lawan melayani dua poin, lalu bergantian dua poin. Advantage set atau tie-break set diumumkan penyelenggara sebelumnya. Match tie-break 10 poin dapat menggantikan set penentu. [ITF Rules of Tennis 2026](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf)
> - Foot fault: selama gerakan servis server tidak boleh berpindah posisi dengan berjalan atau berlari (gerakan kaki kecil boleh), dan tidak boleh menyentuh garis dasar atau lapangan dengan kaki mana pun. [ITF Rules of Tennis 2026](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf)
> - Let servis: bola mengenai net dan servisnya tetap baik, atau servis dilakukan saat penerima belum siap. Servis diulang dan tidak membatalkan fault sebelumnya. Pada semua kasus let, seluruh poin diulang kecuali let pada servis kedua, yang hanya mengulang servis kedua. Beberapa turnamen memakai aturan No-Let. [ITF Rules of Tennis 2026](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf)
> - Hindrance: jika pemain terganggu oleh tindakan sengaja lawan, pemain itu memenangkan poin. Jika terganggu oleh tindakan tidak sengaja atau hal di luar kendali, poin diulang. Raket jatuh atau sepatu lepas tidak dianggap hindrance. [ITF Rules of Tennis 2026](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf) [ITF Duties and Procedures for Officials 2026](https://www.itftennis.com/media/2509/duties-procedures-for-officials-2026.pdf)

## 5.1 Ringkasan format

- Tunggal atau ganda. Best of 3 set (atau satu set untuk mempersingkat ).

## 5.2 Lapangan dan perlengkapan

| Bagian | Ukuran |
|---|---|
| Panjang | 23,77 m |
| Lebar tunggal | 8,23 m |
| Lebar ganda | 10,97 m |
| Tinggi net | 0,914 m di tengah |
| Kotak servis | 6,40 m dari net |

## 5.3 Jalannya pertandingan

1. **Undian**: pemenang memilih servis, return, atau sisi.
2. **Servis**: dari belakang garis dasar, diagonal ke kotak servis lawan. **Dua kesempatan** per poin.
3. **Server berpindah sisi** tiap poin (kanan di poin genap, kiri di poin ganjil).
4. **Servis bergantian** setiap game.
5. **Ganti sisi** setelah game ganjil (1, 3, 5, ...) dengan jeda 90 detik. Setelah set, jeda 120 detik. ⚠️ Verifikasi
6. **Jeda antar poin**: maksimal 25 detik.

## 5.4 Aturan skor

- **Poin**: 0, 15, 30, 40, game.
- **Deuce** (40–40): butuh unggul 2 poin. Poin pertama setelah deuce = *advantage* (Ad). **No-ad**: di deuce, satu poin menentukan game.
- **Set**: sampai 6 game, selisih 2. Jika 6–6: **tie-break**.
- **Tie-break**: sampai 7 poin, selisih 2. Server pertama melakukan satu servis, lalu bergantian dua servis. Ganti sisi tiap 6 poin.
- **Pertandingan**: best of 3 set. Set ketiga bisa diganti *match tie-break* 10 poin.

## 5.5 Kamus istilah dan pelanggaran

| Istilah | Penjelasan detail | Hukuman |
|---|---|---|
| **Foot fault** | Server menyentuh garis dasar atau masuk lapangan, atau melewati perpanjangan imajiner garis tengah atau garis sisi sebelum bola dipukul. Melompat saat servis boleh. | Servis salah |
| **Fault** | Servis tidak masuk kotak servis yang benar. | Satu kesempatan hangus |
| **Double fault** | Dua servis salah berturut-turut. | Poin untuk penerima |
| **Let** | Servis menyentuh net lalu masuk kotak benar. Diulang tanpa mengurangi kesempatan. Juga bila ada gangguan. | Diulang |
| **Hindrance** | Gangguan dari lawan atau dari luar (bola masuk, suara disengaja). | Rally diulang atau poin |
| **Double bounce** | Dua pantulan di sisi Anda. | Poin lawan |
| **Net touch** | Raket, badan, atau pakaian menyentuh net saat bola dalam permainan. | Poin lawan |
| **Carry / double hit** | Bola dibawa di raket atau dipukul dua kali dengan sengaja. Dua kontak tidak sengaja dalam satu ayunan tidak dihitung. | Poin lawan |
| **Reaching over** | Memukul bola di sisi lawan net sebelum bola melewati net (kecuali follow-through). | Poin lawan |
| **Ace** | Servis sah yang tidak disentuh penerima. | Poin server |
| **Out** | Bola mendarat di luar garis. Garis termasuk area masuk. | Poin lawan |

## 5.6 Disiplin dan penalti (Code of Conduct)

| Tingkat | Sanksi |
|---|---|
| Pelanggaran 1 | Peringatan (*warning*) |
| Pelanggaran 2 | Penalti poin |
| Pelanggaran 3 | Penalti game |
| Pelanggaran 4 | Default (DQ) |
| *Time violation* | Peringatan lalu penalti poin (melebihi 25 detik) |
| Pelanggaran berat | Default langsung |

## 5.7 Status hasil

| Istilah | Di tenis |
|---|---|
| **DNS** | Pemain tidak hadir. W/O. |
| **DNF** | Pertandingan tidak selesai. |
| **DQ** | Default setelah code violation berulang atau pelanggaran berat. |
| **Forfeit / W/O** | Tidak hadir atau mundur sebelum atau saat pertandingan. |
| **RET** | Mundur di tengah pertandingan karena cedera. Skor sampai saat itu tetap tercatat. |
| **Let** | Servis kena net lalu masuk kotak benar. Diulang tanpa mengurangi kesempatan. |
| **Fault** | Servis salah = hangus satu kesempatan. Dua kali = *double fault* = poin lawan. |

## 5.8 Perhitungan dan klasemen

- Contoh: 6–3, 6–7(5), 10–8 → pemenang 2–1 set.
- Liga: menang 3 poin (atau 2), tie-breaker selisih set → selisih game.
