# 10. Volleyball (W)

> Kategori: Tim

> **Dokumen acuan:** FIVB, *Official Volleyball Rules*.

> **Terkonfirmasi sumber resmi** · dicek 16 Okt 2026
>
> - Tiap tim boleh menunjuk sampai dua libero. Hanya satu libero di lapangan. Pergantian libero tidak dihitung sebagai pergantian biasa, tidak terbatas, tetapi harus ada minimal satu rally selesai di antaranya. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Maksimal dua time-out dan enam pergantian per set. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Pengusiran ditunjukkan dengan kartu merah dan kuning bersama. Diskualifikasi ditunjukkan dengan kartu merah dan kuning terpisah. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Pemain yang tidak terdaftar ditemukan di lapangan: poin lawan tetap sah, lawan mendapat poin dan servis, tim pelanggar kehilangan poin atau set sebelumnya, dengan skor set dicatat 0:25 jika perlu. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Set 1 sampai 4 dimenangkan tim pertama yang mencapai 25 poin dengan selisih minimal 2 (24–24 lanjut sampai selisih 2). Set kelima, bila 2–2, dimainkan sampai 15 poin dengan selisih minimal 2. Pertandingan dimenangkan tim yang menang tiga set. Pada set penentu, tim berganti sisi saat tim unggul mencapai 8 poin. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf) [Aturan dasar FIVB](https://www.fivb.com/volleyball/the-game/basic-rules/)
> - Tiap tim berhak maksimal tiga sentuhan di luar blok. Sentuhan blok tidak dihitung sebagai sentuhan tim. Lebih dari itu adalah fault "four hits". [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Menyentuh net di antara antena saat memainkan bola adalah fault. Foot fault servis: kaki server menyentuh lapangan (termasuk garis belakang) atau area bebas samping di luar zona servis. Juga kontak yang salah dengan garis serang 3 m, atau kaki melewati garis tengah sepenuhnya. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf) [Video Challenge Regulations](https://www.fivb.com/wp-content/uploads/2024/05/Video-Challenge-System-Regulations-2025_final_v03.pdf)
> - Positional fault: ada pemain tidak di posisi benar saat server memukul bola. Rotational fault: servis tidak sesuai urutan rotasi. Hukumannya poin dan servis untuk lawan. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Serangan pemain belakang baru fault jika pukulan serang selesai (bola sepenuhnya melewati bidang net atau disentuh lawan). Pemain belakang dan libero tidak boleh menyelesaikan atau ikut dalam blok yang selesai. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)
> - Jika dua tim melakukan fault bersamaan, dihitung double fault dan rally diulang. [FIVB Rules 2025-2028 (edisi Prancis)](https://www.fivb.com/wp-content/uploads/2025/06/FIVB-Volleyball_Rules2025_2028-FR-v04.pdf)
> - Jumlah pemain terdaftar: teks Inggris menyebut hingga 12, teks Prancis hingga 14. [FIVB Rules 2025-2028](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)

## 10.1 Ringkasan format

- 6 lawan 6 putri. **Best of 5 set**.
- Berdasarkan aturan **FIVB**.

## 10.2 Lapangan dan perlengkapan

| Bagian | Ukuran |
|---|---|
| Lapangan | 18 m × 9 m |
| Tinggi net putri | 2,24 m |
| Garis serang | 3 m dari net |
| Zona servis | Lebar 9 m di belakang garis belakang |
| Bola | Keliling 65–67 cm, berat 260–280 g |

## 10.3 Jalannya pertandingan

1. **Undian**: pemenang memilih servis atau sisi.
2. **Servis**: dari zona servis, satu percobaan. Bola boleh menyentuh net dan tetap masuk.
3. **Rally**: setiap tim maksimal **3 sentuhan** sebelum mengembalikan bola.
4. **Rotasi**: saat tim mendapat hak servis (memenangkan rally saat menerima), semua pemain berputar satu posisi searah jarum jam.
5. **Libero**: spesialis bertahan dengan seragam berbeda, hanya main di belakang, tidak boleh menyerang di atas net atau servis.
6. **Substitusi**: maksimal 6 per set.
7. **Time-out**: 2 per set (30 detik). Technical time-out di 8 dan 16 poin pada beberapa kompetisi. ⚠️ Verifikasi
8. **Ganti sisi**: setelah tiap set. Di set kelima, saat salah satu tim mencapai 8 poin.

## 10.4 Aturan skor

- *Rally point*: tiap rally = 1 poin untuk pemenang, siapa pun yang servis.
- Set 1–4 sampai **25** poin, selisih 2. Set kelima sampai **15** poin, selisih 2.
- Pertandingan = menang **3 set**.

## 10.5 Kamus istilah dan pelanggaran

| Istilah | Penjelasan detail | Hukuman |
|---|---|---|
| **Double hit** | Satu pemain menyentuh bola dua kali berturut-turut (kecuali pada kontak pertama tim, atau blok). | Poin lawan |
| **Lift / catch** | Bola tertahan atau "diangkat" di tangan, bukan dipantulkan bersih. | Poin lawan |
| **Four hits** | Tim menyentuh bola lebih dari tiga kali. Kontak blok tidak dihitung sebagai sentuhan. | Poin lawan |
| **Net touch** | Pemain menyentuh net saat bola dalam permainan (bagian atas atau pita atas). | Poin lawan |
| **Foot fault (servis)** | Kaki server menyentuh atau melewati garis belakang saat melakukan servis. | Poin lawan |
| **Rotation fault** | Servis dalam urutan rotasi yang salah. | Poin lawan, dan koreksi urutan |
| **Positional (overlap) fault** | Pemain tumpang tindih posisi saat servis. | Poin lawan |
| **Back-row attack fault** | Pemain belakang menyerang dari depan garis 3 m saat bola di atas net. | Poin lawan |
| **Blocking fault** | Memblok servis lawan, atau memblok dari luar antena. | Poin lawan |
| **Ball out** | Bola mendarat di luar garis, atau menyentuh benda di luar lapangan. Garis termasuk area masuk. | Poin lawan |
| **Antenna** | Bola menyentuh antena atau melewati di luar antena = out. | Poin lawan |
| **Replay** | Rally diulang jika dua tim melakukan pelanggaran bersamaan atau ada gangguan dari luar. Padanan dari *let*. | Diulang |

## 10.6 Disiplin dan penalti

| Tingkat | Sanksi |
|---|---|
| **Peringatan (kuning)** | Tanpa penalti |
| **Penalti (merah)** | Poin untuk lawan |
| **Pengusiran (kartu merah dan kuning ditunjukkan bersama)** | Pemain keluar untuk sisa set |
| **Diskualifikasi (kartu merah dan kuning ditunjukkan terpisah)** | Pemain keluar untuk sisa pertandingan |
| **Delay warning / delay penalty** | Peringatan lalu penalti atas penundaan permainan |

## 10.7 Status hasil

| Istilah | Di voli |
|---|---|
| **DNS** | Tim tidak hadir, W/O. |
| **DNF** | Pertandingan dihentikan. |
| **DQ** | Pemain atau tim didiskualifikasi karena kartu merah dan kuning yang ditunjukkan terpisah atau pelanggaran berat. |
| **Forfeit / W/O** | Tim tidak hadir: kalah 0–3 dengan skor 0–25 di tiap set. Tim kurang dari 6 pemain = *incomplete*, kalah set atau pertandingan. |
| **RET** | Pemain cedera diganti. Jika tak ada pengganti, tim *incomplete* dan kalah set. |
| **Let** | Disebut ***replay***: rally diulang. |
| **Fault** | Rally hilang = **poin ke lawan** (*rally point*). Servis salah juga langsung poin lawan. |

## 10.8 Perhitungan dan klasemen

- **Contoh pertandingan**: 25–20, 22–25, 25–23, 25–18 → pemenang 3–1 set.
- **Poin liga (FIVB)**:

| Hasil | Poin pemenang | Poin kalah |
|---|---|---|
| 3–0 atau 3–1 | 3 | 0 |
| 3–2 | 2 | 1 |

- **Tie-breaker**: jumlah kemenangan → poin → rasio set → rasio poin → head-to-head. ⚠️ Verifikasi
